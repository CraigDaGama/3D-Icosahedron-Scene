# 3D Icosahedron Scene

This project demonstrates a basic 3D scene built with **Three.js**. It features an interactive **icosahedron geometry**, rendered with a combination of wireframe and solid materials. The scene is fully navigable using the **OrbitControls** to rotate and zoom around the 3D object.

## Features
- **Icosahedron Geometry**: A polyhedron with 20 triangular faces.
- **Materials**: The object is rendered with both a solid `MeshStandardMaterial` and a `MeshBasicMaterial` for the wireframe.
- **Orbit Controls**: Allows the user to interact with the scene by rotating, zooming, and panning the camera.
- **Lighting**: Uses a **HemisphereLight** for basic ambient and directional lighting.
